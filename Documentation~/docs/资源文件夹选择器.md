# 资源文件夹选择器

## 设计说明

这是一个完全独立的 Unity Editor 工具，用于在 Sprite、材质等资源数量较多时，先按文件夹缩小候选范围，再选择具体资源。

- 原版 `ObjectField` 保留不变，新增独立的文件夹筛选入口。
- 文件夹范围从项目 `Assets` 根目录开始。
- 可选择当前文件夹，或包含所有子文件夹。
- 资源类型由调用方指定，选择结果必须符合类型约束。
- 点击资源即完成选择，窗口保持打开。
- 支持资源索引缓存、完整目录开关、小中大缩略图、可拖拽目录栏和搜索目录联动。
- 关闭窗口时保存当前资源类型的文件夹位置。
- 不修改资源，不进入游戏运行时，不依赖 ReactUI 或其他项目程序集。

## 开发说明

工具使用独立的 `SimOverride.AssetPicker.Editor` 程序集和 `AssetDatabase` 查询资源，并按资源类型缓存索引。项目变化或点击“刷新”时清理缓存。最近文件夹位置、目录过滤开关、缩略图尺寸和目录栏宽度保存在当前用户的 `EditorPrefs` 中，不生成项目配置文件。

公开入口包括资源字段绘制方法和直接打开窗口的方法，目标项目的 Editor 程序集可以按需调用。

## 使用说明

1. 导入 `.unitypackage`，或安装 UPM 包。
2. 在目标 Editor 程序集引用 `SimOverride.AssetPicker.Editor`。
3. 使用 `AssetPickerField.Draw` 替换需要增强的资源字段。
4. 点击字段右侧文件夹按钮。
5. 选择文件夹后，在右侧点击 Sprite、Material 等目标资源；可以用工具栏开关显示完整目录、调整缩略图大小，并拖拽左侧目录栏宽度。

启用目录过滤时，搜索条件也会同步减少左侧文件夹。窗口关闭后，下次打开相同资源类型会恢复上次使用的文件夹。点击资源会立即回调，但窗口不会关闭。
